# My Website

This is just a static website using [hugo](https://gohugo.io) and [hugo awesome blog](https://github.com/hugo-sid/hugo-blog-awesome)

## Clonning this repo with submodule

Here are some commands for me, if I want to clone this repo (In case I forgot which command was it).

### `https`

```bash
git clone --recurse-submodules https://github.com/harshv5094/harshv5094.github.io website/
```

### ssh

```bash
git clone --recurse-submodules git@github.com:harshv5094/harshv5094.github.io website/
```
